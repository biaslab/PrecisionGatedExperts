Key Insight

Quality depends only on α, not on β. Rate just shifts the location on log-scale.

KL = log Γ(α) − (α − ½) ln α + α − ½ ln 2π

This equals the error in Stirling's approximation — so the LogNormal approximation inherits the same convergence rate.

α ≥ 5 → KL < 0.02 (excellent)
α ≈ 1 → KL ≈ 0.08 (fair)
α < 0.5 → poor (Gamma has 0-singularity)
